                                  ADP for each format is derived as (expert consensus rank + ECR"‘vs"‘ADP) from the FantasyPros export - directly sourced, not estimated. Players with no market ADP on file default to their consensus rank. Half-PPR is the one exception: FantasyPros doesn't publish a separate Half-PPR consensus export, so those rank/ADP/tier values are interpolated as the midpoint between the sourced PPR and Standard numbers rather than independently sourced - treat Half-PPR as directional, not as precise as the PPR/Standard columns.
                                  Superflex QB tiers are sourced directly from FantasyPros' 2026 Superflex Rankings (Pat Fitzmaurice). Turning the toggle on reorders every QB's Tier/ADP/Rank on the board itself (not just a side badge) using a derived overall placement: each QB's sourced tier is mapped into an overall pick number using that same FantasyPros piece's own round-band guidance (Tier 1-2 -> rounds 1-2, Tier 3-4 -> rounds 3-5, Tier 5-9 -> rounds 6-9), spread evenly within each band and tie-broken by the QB's single-QB rank. This placement is a **derived estimate, not an independently sourced overall Superflex ADP/consensus export** - no such full-position cross-reference export exists publicly the way the PPR/Standard ones do - so treat exact Superflex pick numbers as directional. Non-QB players are completely unaffected: their rank/ADP/tier/Value stay exactly what the selected scoring format already says. QB Value chips show "Fair" under Superflex rather than Steal/Reach/Avoid, since there's no independent market-vs-consensus signal for a derived number to compare itself against. QBs outside FantasyPros' explicitly ranked tiers (deep backups) are grouped into an unranked "SF T10" bucket rather than individually ordered.
                                  Handcuff pairings, tier-break dividers, and bye-week collision checks (4+ shared byes) are computed live from this dataset, not separately sourced. Offensive line and schedule context are shown informationally in each player's detail panel and are not folded into confidence scores or value ratings.
                                  Personal favorites, notes, and any News Log items you add yourself are saved automatically in this browser's local storage on this device - there's still no server or database behind this file, so nothing is sent anywhere, and none of it appears for anyone else unless you share it. Use the "Export my data"/"Import my data" buttons (top right) to carry them to a different device/browser or to keep a backup file, the same way "Export/Import state" would work for the Live Draft Companion. If this page is ever opened in a private/incognito window, local storage may not persist - export before closing in that case.
                                  News Log source links are shown only where a real, checkable link exists - either from this assistant's own research or from a link you paste in yourself.
